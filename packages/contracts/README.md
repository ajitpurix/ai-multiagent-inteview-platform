# @ai-interview/contracts

Shared TypeScript schemas, interfaces, enums, and event definitions used across all services in the AI Interview Platform.

## Contents
- **Entity Models**: `UserProfile`, `InterviewSession`, `InterviewQuestion`, `CandidateAnswer`, `EvaluationReport`.
- **Code Execution**: `CodeExecutionRequest`, `CodeExecutionResponse`.
- **Event Messaging**: `EventTopics`, `EventEnvelope`.

## Usage
```ts
import { InterviewSession, InterviewStatus, EventTopics } from '@ai-interview/contracts';
```
